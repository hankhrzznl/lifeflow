# LifeFlow 等级制账户解锁机制设计（v1.0，2026-08-22）

> **缘起**：用户对「今日盘面 + 今日格子墙」的概念不满意（2026-08-22）。提出新方向——**像游戏等级一样解锁所有功能**：四个账户作为成长主线，初始 1 级只有体能账户（睡眠可用），升级解锁下一个账户及其功能；升级条件综合「是否每天使用」+「是否达到自定目标」两个因子。本文件将用户想法完善为完整等级体系，取代原「渐进解锁（格子墙）」成为产品长期成长轴。
> **关系**：等级制 = 渐进解锁的**概念升级**（从"格数"到"账户+等级"）；能量档位（日内轴）保持正交不变。

---

## 一、概念定位（为什么是等级制）

| 对比 | 旧：渐进解锁（格子墙） | 新：等级制账户解锁 |
|---|---|---|
| 成长单位 | 格子（6 格） | **账户 + 等级**（7 级） |
| 用户看到 | 进度条墙（一堆待解锁格） | **一个等级 + 下一级差什么** |
| 升级依据 | 单格达标率 ≥70% | **使用率 × 达标率双因子**（用户指定） |
| 解锁对象 | 维度格 | **账户 + 该账户的功能** |
| 叙事 | 积累格子 | **账户成长：体能 → 情感 → 思维 → 意志** |
| 游戏感 | 弱（列表式） | 强（等级徽章 + 解锁时刻 + 成长条） |

**核心叙事**：用户不是在管理 6 个格子，而是在**经营自己从 1 级到满级的成长**。每个等级 = 一个账户被点亮 + 一组功能被开启。这与「能量经营」完全同向——四账户本身就是等级主线的四个节点。

**与能量档位的关系（不变）**：
- 能量档位（日内）：今天状态差 → 今日轻载呈现（明日恢复）
- 等级制（长期）：你当前管理几个账户
- 正交相乘：今日呈现 = 等级决定功能范围 × 档位决定轻载程度

---

## 二、等级阶梯（7 级总设计）

用户要求设计「达到解锁所有功能需要多少级」——设计为 **7 级**：前 4 级为账户主线（成长感核心），后 3 级为功能深化（主线到全功能）。

```
Lv1 ── 体能账户（新手 · 只做睡眠）
      解锁：体能账户 · 睡眠记录
      可用：睡眠（今天页只有这一件事）+ 安排页可排日程
      升级：睡眠使用率 ≥5/7 ∧ 睡眠达标率 ≥5/7（近 7 天滚动）
Lv2 ── 情感账户（觉察开启）
      解锁：情感账户 · 情绪记录
      升级：情绪累计使用满 7 天
Lv3 ── 思维账户（专注开启）
      解锁：思维账户 · 专注
      升级：专注累计使用 ≥7 小时
Lv4 ── 意志账户（目标开启 · 四账户主线完成）
      解锁：意志账户 · 完整目标功能（方向页 + TodayStep + 目标创建/详情）
      升级：TodayStep 累计推进 14 天（目标行动完成 ≥1 次/天 计 1 天）
Lv5 ── 体能深化（生理全模块）
      解锁：饮水 · 训练 · 饮食 · 久坐 · 习惯
      升级：目标推进保持 7 天（Lv4 条件延续）∧ 任意 1 个新模块使用 ≥3 天
Lv6 ── 生活工具（工具开启）
      解锁：备忘 · 倒数日 · 提醒
      升级：Lv5 解锁模块整体使用 ≥7 天
Lv7 ── 完整版（全功能）
      解锁：陪练完整版 · 记账 · 吃药 · 功法养生 · 设置全功能
      升级：所有已解锁模块使用 ≥7 天
```

**设计理由**：
- **前 4 级 = 四账户**（用户核心想法）：体能 → 情感 → 思维 → 意志，每级点亮一个账户徽章
- **Lv1 只有睡眠**（用户指定）：新用户从"只做一件事"开始，符合②门槛低
- **Lv2 条件**（用户指定）：睡眠双因子升级后，情绪用 7 天
- **Lv3 条件**（用户指定）：专注累计 7 小时（"小时"级门槛，鼓励真实投入而非打卡）
- **Lv4 目标**（用户指定"完整版目标功能"）：TodayStep 14 天是"意志账户"的实质证据
- **Lv5-7 深化**（我补充）：主线完成后按"生理 → 工具 → 完整"自然扩展，避免一步全开（②）

## 三、升级条件双因子公式（用户指定核心）

**通用原则**：每个等级的升级条件 = **使用率 × 达标率综合**，不是单一维度。

| 因子 | 定义 | 计算 |
|---|---|---|
| **使用率 U** | 是否每天都用 | 近 7 天使用天数 / 7（睡眠等每日型）或累计使用（情绪 7 天 / 专注 7 小时 / TodayStep 14 天） |
| **达标率 T** | 是否达到用户自定的目标 | 近 7 天达标天数 / 7（睡眠达标 = isOnTime；专注达标 = 目标时长） |

**等级间条件一览**（含用户指定的累计型）：

| 升级 | 条件 | 类型 |
|---|---|---|
| Lv1→2 | 睡眠 U≥5/7 ∧ T≥5/7 | 每日型双因子 |
| Lv2→3 | 情绪累计使用 7 天 | 累计型 |
| Lv3→4 | 专注累计 ≥7 小时 | 累计型 |
| Lv4→5 | TodayStep 推进 14 天 ∧ 新模块用 ≥3 天 | 累计型 |
| Lv5→6 | 已解锁模块整体使用 ≥7 天 | 累计型 |
| Lv6→7 | 全部已解锁模块使用 ≥7 天 | 累计型 |

## 四、关键规则（六句话防护）

| 规则 | 理论 | 说明 |
|---|---|---|
| **失败不降级** | ⑤ | 等级只增不减；掉出条件只是"暂缓升级"，已解锁功能永不收回（沿用原渐进解锁铁律） |
| **老用户不重新爬塔** | ② | 按近 7 天数据直接定级（首日可能即 Lv4/Lv5）；重新爬塔 = 惩罚老用户 |
| **解锁时刻 = 庆祝** | ⑤ | 全屏轻庆祝 + 教练句：「情感账户已开启。情绪记录今天可用。」（被看见的小胜） |
| **未解锁功能 = 灰态可见** | ⑤② | 显示成长路径但不可用（如方向页显示「Lv4 开启 · 目标功能」）——动机可视化，不一次加满 |
| **低能量日不影响等级** | ② | 档位是日内形态；等级只看长期使用与达标 |
| **升级条件对用户透明** | ① | 等级页明确展示「下一级还差什么」（还差 X 天使用 / X 小时专注） |
| **禁用词防护** | 文案宪法 | 等级描述零「失败/未完成/断签/掌控」；未解锁 = 「Lv4 开启」正向表述 |

## 五、呈现变化（与旧概念对比）

### 今天页（替代盘面 + 格子墙）

```
Lv2 · 情感账户已点亮
┌─────────────────────────────┐
│  等级徽章 Lv2   成长条 → Lv3 │  ← 等级身份（替代盘面）
│  下一级：专注 · 还差 3 小时    │
└─────────────────────────────┘
┌─────────────────────────────┐
│  配速员：情绪平稳，今天可以     │  ← 一句感知（替代四账户盘面）
└─────────────────────────────┘
┌─────────────────────────────┐
│  ▸ 今日主行动（策略引擎推 1 件） │  ← 一行动（替代格子墙操作）
│     记录情绪 → 3 秒完成        │
└─────────────────────────────┘
┌─────────────────────────────┐
│  已完成：睡眠 ✓ 情绪 ✓        │  ← 今日小胜（⑤看见小胜）
└─────────────────────────────┘
```

- 已解锁功能以「今日主行动 + 小胜列表」呈现（不再是 6 格墙）
- 未解锁功能不显示在操作区，只出现在等级成长提示中
- 低能量日：主行动自动降为最轻版本（如「今晚 23 点前睡」）

### 我的页（等级身份卡，替代进阶路径卡）

```
┌─────────────────────────────┐
│  Lv2 · 情感账户已点亮          │
│  体能 ✓ 情感 ✓ 思维 → 意志 →   │  ← 四账户徽章点亮进度
│  下一级 Lv3：专注 · 还差 3 小时  │
└─────────────────────────────┘
```

### 安排页（分等级可用性）

| 等级 | 安排页可用 |
|---|---|
| Lv1 | 可添加日程（时间轴 + 手动添加） |
| Lv2 | 同上 |
| Lv3 | 同上 + 专注时段自动排入 |
| Lv4 | 同上 + 目标行动自动排入（TodayStep → 时间轴） |

### 方向页（分等级可用性）

| 等级 | 方向页 |
|---|---|
| Lv1-3 | 灰态锁定：「Lv4 开启 · 目标功能」（成长路径可见） |
| Lv4 | 完整目标功能（TodayStep 置顶 + 三层目标 + 创建/详情） |

## 六、数据与实现（零 schema 变更）

- **判定**：纯读现有表（sleepLogs/healthDB、moodLogs、focusSessions、goalV2DailyActions 等）+ localStorage
- **存储**：`localStorage`（unlockLevel / 各级解锁日期 / 累计使用计数）——沿用现有模式
- **函数**：扩展 `src/lib/unlock.ts` → `getUnlockState(): { level, unlockedAccounts[], unlockedFeatures[], next: {label, progress} }`（从 CellId 版改为 Account+Feature 版）
- **升级检查时机**：每天首次打开今天页（与能量判定同批）
- **累计计数**（情绪 7 天 / 专注 7 小时 / TodayStep 14 天）：localStorage 存累计值，读表增量更新

## 七、验收

- 新用户首日：Lv1，今天页只有睡眠一件事 + 等级成长条（Lv2 还差 X 天）
- 睡眠 5/7 使用 ∧ 5/7 达标 → Lv2 解锁，情绪出现，庆祝动画
- 情绪累计 7 天 → Lv3，专注出现
- 专注累计 7 小时 → Lv4，方向页全功能解锁
- 老用户（30 天数据）：首日直接定级，无爬塔
- 既有功能掉出条件：等级保留，仅暂缓升级
- 文案零「失败/降级/未完成/断签」
- 方向页 Lv1-3 灰态可见「Lv4 开启」；Lv4 后完整可用
