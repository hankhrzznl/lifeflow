# LifeFlow 推倒重做 · 完整步骤方案（2026-08-22 拍板）

> **决策**：重构（批次 1-8）不够——那些是在旧骨架上打补丁。重做 = 从能量经营方案出发**全新设计信息架构与页面形态**，不受四代历史演化（导航系→量化引擎→六句话→能量经营）的路径依赖。

## 二、新信息架构（IA v2 · 能量经营原生）

### 底导 4 tab（推荐，可调）

```
今天        安排         方向        我的
盘面+格子墙   时间轴+攻坚窗口  目标+TodayStep  回顾+习惯+账户详情+系统
（一日经营）  （思维账户经营） （意志账户）    （收口与管理）
```

> 备选：保持 现有 4 tab（今天/目标/今日安排/更多）语义只换内部——如果不想动用户习惯。**推荐新 4 tab**：「安排」比「今日安排」短、「方向」承载意志账户语义、「我的」收拢回顾+管理。

### 页面清单（新画布从零建）

**P0 核心四页**（底导）
1. **今天**：等级徽章 + 成长条（替代四账户盘面）→ 配速员一句感知 → 今日主行动（策略引擎推 1 件）→ 今日小胜列表（完成即喊）；未解锁功能不显示在操作区，只出现在等级成长提示
2. **安排**：攻坚窗口区块 → 时间轴（留白 ≥30%）→ 实际节奏卡 → 添加（唯一 primary）；Lv1 只能添加日程，Lv3 起专注时段自动排入，Lv4 起目标行动自动排入
3. **方向**：今天这一步（TodayStep 置顶）→ 目标列表（3 层）→ 连续推进；Lv1-3 灰态锁定（「Lv4 开启 · 目标功能」），Lv4 全功能解锁
4. **我的**：等级身份卡（四账户徽章点亮进度 + 下一级差什么）→ 推进回顾入口（含小胜摘要）→ 习惯管理 → 账户详情组（8 冻结页入口+情绪）→ 工具 → 系统

**P1 流程页**
5. 推进回顾（小胜计数+账户周报+lag-1+维度折叠+下周计划）
6. 专注格（5 分钟默认+沉浸+完成双出口+锚点）
7. 情绪（3 秒记录+标签）
8. 陪练（盘面感知+时段静默）
9. 目标创建（3 层 ≤5 字段）/ 目标详情（TodayStep+高级视图）

**P2 支撑页**
10. onboarding（3 步）11. 提醒 12. 倒数日 13. 备忘 14. 设置 15. trash

**冻结对接**：8 冻结页保持现 src 实现，新画布只做「壳层对接卡」（入口位/返回逻辑/主题一致性）——每次动壳层前告知。

## 四、风险与纪律

1. **数据安全**：任何 Phase 不碰 Dexie schema；src 重做只换 UI 层引用
2. **冻结流程**：8 页的任何修改（含壳层）→ 先告知（改什么/为什么/风险）→ 用户确认 → 执行
3. **不返工原则**：每个 Phase 画布定稿后才进 src（画布是沙盒，改画布便宜）
4. **防复发**：新 IA 页面清单即「入口唯一性」的事实源——任何入口增删先对照本方案第二节
5. **术语纪律**：全部新页面引用 terms.ts，禁用词零命中
