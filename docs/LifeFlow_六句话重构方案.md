# LifeFlow 六句话重构方案（结构级，2026-08-22）

> **任务**：用六句话重构产品——不是页面微调，是**结构重排**。
> **方法**：保留产品本质（掌控生活操作系统 / 五层闭环 / 本地优先 / 设计系统），改变结构（页面拓扑 / 层级深度 / 模块权重），让六句话成为结构本身而非补丁。

---

## 〇、先对齐：什么叫「重构」

| | 含义 | 对应到本产品 |
|---|---|---|
| **优化** | 局部改（文案/样式/单个功能） | 之前几轮做的：提示词包 R1-R6、V1.5-A 设计——**这是优化，不是重构** |
| **重构** | 保持外部行为与核心价值，改变内部结构 | 本次要做的：**页面拓扑、层级深度、模块权重**重排；产品本质（掌控生活操作系统）与设计系统（colors_and_type.css）不动 |
| **重写** | 推倒重来 | 不需要——底层数据层（Dexie 8 模块）+ 五层闭环 + 禁词哲学本来就对 |

**为什么六句话要求的是重构而非优化**：因为它们指出的问题**都在结构层**——回顾页埋在第 3 层（⑤小胜主阵地藏最深）、目标 5 层拆解（②④）、更多页 11+ 入口（①）、睡眠无底线地位（⑥）。**补丁修不了结构**。

---

## 一、结构级诊断（实证）

| 六句话 | 结构问题（全部实证） |
|---|---|
| ① 切换损耗 | 「更多」页 3 组 ~11-12 功能入口；习惯/冥想等与进度条墙格子**双入口重复**（同一动作两个页面） |
| ② 意志力 + ④ 规划谬误 | **目标 5 层拆解**（Goal→KeyResult→Strategy→WeeklyTask→DailyAction，goal-v2.db 实证）= 深度认知消耗 + 「按理想状态规划」的结构化表达 |
| ⑤ 进步原则 | **回顾页埋在第 3 层**（底导→更多→推进回顾，BottomTabBar 实证：底导只有 今天/目标/今日安排/更多）——「小胜被看见」的主阵地在结构最深处 |
| ③ 反刍 | 回顾页内容以对比统计为主（lag-1 分组对比 + 维度点阵），**无「小胜优先」框架** |
| ⑥ 睡眠底线 | 睡眠只是进度条墙 6 格之一，**无底线结构地位**（破了底线与破了任何一格视觉等价） |

## 二、重构指令（5 条结构变更）

### R-1｜目标拆解：5 层 → 3 层（②④⑤）

```
现状：Goal → KeyResult → Strategy → WeeklyTask → DailyAction（五层）
重构：Goal（方向）→ Milestone（阶段）→ TodayStep（今天这一步）
      ——Strategy/WeeklyTask 降为「高级视图」默认折叠（深度用户可选展开）
```

- 今天页 / 教练卡 / 焦点格**只引用 TodayStep 层**（「今天只做一件事」的数据源就是它）
- ⑤：每完成一个 TodayStep = 一次小胜被看见（联动 R-3）
- ④：创建流程只要求 3 层（方向 + 阶段 + 下一步），系统从历史实际速度反推中间安排（规划校准联动）

### R-2｜习惯页：合并降级（①⑤）

```
现状：习惯独立页（打卡）+ 进度条墙习惯格 = 双入口重复
重构：打卡动作收进今天页习惯格（唯一入口）
      习惯页降级为「习惯管理页」（增删/频率/历史，更多页内标注「管理」）
```

- 收益：消除双入口切换损耗；习惯完成 = 格完成 = 小胜显性化（⑤链路打通）
- 待拍板：D2 保留管理页（推荐）还是完全删除

### R-3｜回顾页：重做 + 抬升（⑤⑥③，本次重点）

**抬升（结构）**：在**今天页 Hero 区下方加「昨日小胜」条**——把回顾的最小单元抬到每天必经页面：

```
┌────────────────────────────────────┐
│ 昨天：专注 2 段 · 饮水 2100ml · 入睡 22:40 ✓│  ← 只列完成的，零「未完成」
└────────────────────────────────────┘
```

**重做（内容框架）**：推进回顾页重排——

```
1. 顶部：本周小胜计数「本周你完成了 14 次行动」（⑤核心，正向计数）
2. 连续推进条「连续 5 天至少推进 1 格」
3. lag-1 关联洞察（含⑥睡眠假象破除卡：「少睡日的专注平均少 18 分钟」——用户自己的数据做解药）
4. 维度点阵/细节统计 → 默认折叠（主动展开才看对比数据，③⑤防护）
5. 下周计划卡（H 项挂载点）
```

### R-4｜「更多」页收敛（①）

```
现状：3 组 ~11-12 功能（计划与推进回顾 7 + 身体养护 8 + 记录财务 3）
重构：模块页全部「详情页化」——记录动作收进今天页（六格 + 状态打卡 + 专注入口），
      模块页只承载历史 / 设置 / 详情
组重排：
  组1 计划与回顾：目标 / 推进回顾 / 节奏方案 / 备考目标（4）
  组2 身体详情：睡眠 / 饮水 / 饮食 / 久坐 / 吃药 / 功法 / 训练 / 情绪（8，详情入口）
  组3 工具：记账 / 备忘 / 倒数日 / 到点提醒（4）
  低频模块（冥想/功法/吃药）默认折叠「按需启用」（呼应既有裁决：记账/冥想手动启用）
```

### R-5｜睡眠抬格（⑥）

- 进度条墙：睡眠格获得「底线」视觉语义（首格固定 + 独特标识样式）
- 能量档位 S0 一票降档已设计（V1.5-A v4）
- 下一步建议睡眠优先（睡眠不足日教练卡 =「今晚 23 点前睡」）

> 与《低能量行为设计_画布重做提示词包》的关系：**规则级（R1-R6）管页面内部，本提示词（R-1~R-5）管页面拓扑**——两者合并使用。

```

   goal-create 表单只收 3 层；Strategy/WeeklyTask 折叠为高级视图。
2. 习惯打卡并入今天页习惯格；habit.html 改为管理页（增删/频率/历史），
   删除页内打卡主按钮。
3. 回顾页重做：①今日页 Hero 下加「昨日小胜」条（只列完成项）②review.html
   内容序：本周小胜计数 → 连续推进 → lag-1 洞察（含睡眠假象破除）→ 维度折叠。

   记录主按钮（记录只发生在今天页），保留历史与设置；冥想/功法/吃药折叠。
5. 睡眠格置首格 + 底线标识样式。
叠加《低能量行为设计_画布重做提示词包》R1-R6 页面内规则与验收清单执行。
```

## 四、专家团使用建议（当前 Expert = DesignEngineTeam，5 角色适配）

| 流水线环节 | 角色 | 重构中的职责 |
|---|---|---|
| 1 需求发现 | discovery-analyst | 六句话 × 现状 JTBD 复核；本文 D1-D5 决策点的选项支撑 |
| 2 设计系统 | design-system-expert | 结构变更后 token / 栅格 / 组件一致性校验（如「昨日小胜」条的新组件 token） |
| 3 原型构建 | prototype-builder | 按第三节提示词执行画布结构重排（41 页） |
| 4 质量评审 | critique-reviewer | 六句话验收清单（提示词包 14 条）+ 结构验收门禁（R-1~R-5 逐条过） |
| 5 交付 | export-specialist | 画布 → src 像素级回灌（现有流程沿用） |

**战略拍板分工**：D1-D5 属产品战略决策，由你（owner）拍板；discovery-analyst 负责把每个决策的选项/影响整理成可拍板卡片。**建议顺序**：先拍 D1-D5 → 再走流水线执行，避免做了再返工。

## 六、风险与边界

- **数据层零变更**：R-1 只改展示与创建流程，goalV2 五表 schema 不动（Strategy/WeeklyTask 表保留，UI 折叠）——数据不丢铁律不破
- **术语不变**：推进回顾 / 习惯 / 目标等术语沿用 terms.ts
- **设计系统不变**：colors_and_type.css 唯一 token 源
- **回滚路径**：所有结构变更走画布先行（prototype-builder），src 回灌待验收通过后——画布是安全沙箱
