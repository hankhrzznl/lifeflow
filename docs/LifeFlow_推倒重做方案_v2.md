## 一、理论底座（重做不动的四梁八柱）

### 1.1 定位（源：《六句话重构总方案》§1.1，唯一事实源）

本质：让人掌控每个生活维度的完整生活操作系统（掌控 = 系统替你盯着全局）。对外一句话：「让大目标落地而不崩盘」。五层闭环：方向 → 计划 → 记录 → 洞察 → 调整。主画像：22–28 岁备考青年。本地优先，数据不丢铁律。

### 1.2 六句话宪法（验收时逐条过）

| # | 宪法 | 理论依据 | 操作化 |
|---|---|---|---|
| ① | 一次一事 | 切换损耗 | 每页一个主行动 |
| ② | 门槛低到不会失败 | 福格行为模型 | 默认值 = 最小版本；降门槛不拉动机 |
| ③ | 零反刍 | 耶鲁相关研究 | 提示层零回顾陈述、零评价零安慰 |
| ④ | 计划留白 | 规划谬误 | 时间轴留白 ≥30% |
| ⑤ | 看见小胜 | 哈佛进步原则 | 完成 1 秒内被看见 |
| ⑥ | 守住睡眠底线 | 生理优先级 | 睡眠不足一票降档 |

### 1.3 文案宪法 + 禁用词（源：terms.ts，代码为准）

文案宪法四条：零回顾陈述 / 零评价零安慰 / 一句现在+一个下一步 / 主按钮唯一。禁用词全集（`src/lib/terms.ts` BANNED_WORDS）：理想、失败、未完成、断签、掌控、AI；另禁激励语（加油/坚持/努力/自律）与旧术语（复盘→推进回顾等迁移映射）。

### 1.4 能量经营方案（日内轴）

四账户（体能/情感/思维/意志）× 充值工具 × 支出防护 × 恢复机制；盘面三态（赤字/平衡/充盈）决定当日策略；六句话 = 防守纪律，播客 = 进攻方法。

### 1.5 两期播客源材料（重要更正 + 落地映射）

全库检索确认：**不存在独立的博客文档**。所称"两个博客"实为两期播客笔记——《纵横四海 · 精力四大账户》与《有序生活 · 生活 SOP》，内容仅落盘于 `specs/LifeFlow_精力四账户模型.md`（已归档）并融合进《能量经营方案》。若另有所指，请提供文件名。其核心原则的产品落地映射：

| 播客原则 | 现状 | v2.0 处置 |
|---|---|---|
| 铁则：睡眠 > 饮食 > 运动 | 能量引擎 S0 睡眠一票降档 ✓ | 保留；策略引擎建议排序须同序（验收项） |
| 接受不完美（70% 弹性） | 无显式引用 | **等级制 v3 的全部阈值按"约 70% 弹性练习密度"校准**（v3 §3）——此原则已显式引用为阈值依据 |
| 「运动坚持不了不是不自律，是方式错」 | 文案宪法零评价 ✓ | 保留；陪练建议必须给"换方法"而非"再坚持" |
| 80/20 饮食 | 饮食页（冻结页） | 记入待办：方向为粗粒度 80/20 记录，不做精确卡路里（动冻结页前先告知） |
| 运动后 1–2h BDNF 学习窗口 | 无 | 记入待办：安排页/策略建议候选（训练后排专注） |
| 站桩/恢复性运动、晨练优先 | 训练模块部分 | 记入待办 |
| 「丰富的平静」终点态 | 无 | 已在等级制 v3 落地（P5 支柱）：Lv7 = 丰富的平静 · 四账户安稳视图 |

### 1.6 等级制（长期轴，唯一事实源）

《LifeFlow_等级制账户解锁机制设计_v3》（理论底座推导版：定位 → 六句话 → 两期播客推出）：七级展开式阶梯、条件全单调累计（无失败）、卡壳换方法机制、终点态 = 丰富的平静。与能量档位正交相乘（日内 × 长期）。
