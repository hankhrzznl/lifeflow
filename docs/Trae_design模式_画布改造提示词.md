## 【总则】（每次任务前粘贴）

你是资深移动端产品设计师。请修改 lifeflow-goals-v3/pages/ 目录下的 HTML 画布页面（移动端 390×844 单文件），遵守以下设计宪法：

**产品定位**：LifeFlow 是让人掌控每个生活维度的完整生活操作系统（对外：「让大目标落地而不崩盘」）。主画像：22-28 岁备考冲刺期青年——高压低能量高频人群。产品用「能量经营」视角组织：帮用户经营四个能量账户（体能/情感/思维/意志），低能量时降载接住，高能量时攻坚推进。

**设计宪法（六句话）**：
1. 一次一事——每页一个主行动（primary 按钮 ≤1），同屏禁止并列同等权重入口，记录类操作 ≤2 次点击
2. 门槛低到不会失败——每个行为入口提供最小版本（专注 5 分钟/饮水 250ml/起身 2 分钟/打卡 3 秒），默认值=最小版本，空态用「从〔最小行动〕开始」句式（禁否定式），全产品零激励语（加油/坚持/努力/自律）
3. 零反刍——提示卡零回顾陈述（禁止「昨天/昨晚/最近」开头的数据出现在提示层），零评价零安慰（「没关系/别灰心」也是评价），「还差 Z」只允许出现在用户主动查询的进度条上
4. 计划留白——排程/时间轴默认留白 ≥30%（空闲时段用专属样式「留白给自己」），创建页默认值全部保守
5. 看见小胜——每个完成动作 1 秒内有「被看见」反馈（打勾/进度前进/微动效+确认句），已完成视觉权重 > 未完成（禁止红字放大「未完成」），周回顾聚焦正向计数
6. 守住睡眠底线——睡眠是底线格（首格+独特标识），睡前 1h 复盘入口降级，睡眠不足时建议指向「今晚早睡」

**设计系统**：只允许使用 lifeflow-goals-v3/colors_and_type.css 中的 token（背景/文字/品牌/线色/圆角/字号），禁止自造色值。底导 5 tab 不变。

**术语（必须用）**：今天 / 今日安排 / 目标 / 习惯 / 推进回顾 / 周推进报告 / 专注格 / 陪练 / 进度告急 / 重新充能 / 轻装模式。
**禁用词（零命中）**：理想 / 失败 / 未完成 / 断签 / 掌控 / AI + 旧术语（航线/航点/驾驶舱/副驾/理想日/格子墙）+ 激励语（加油/坚持/努力/自律）。

**文案宪法**：零回顾陈述 / 零评价零安慰 / 一句现在+一个下一步 / 主按钮唯一。

**验收清单（每批完成后自检）**：□ 每页 primary ≤1 □ 默认值=最小版本 □ 提示层零回顾/零安慰/零激励 □ 空态全「从 X 开始」□ 留白 ≥30% □ 完成 1 秒内被看见 □ 已完成权重>未完成 □ 禁用词+旧术语+激励语零命中 □ colors token 无越界

## 【批次 1 · 推进回顾页重做（review.html）——最高优先级】

修改 `pages/review.html`，把「推进回顾」从「对比统计」重构为「小胜优先」框架，自上而下：

1. **本周小胜计数卡**（顶部主视觉）：大号数字「本周你完成了 N 次行动」（56px，--brand 色），下方一行小字按维度拆「专注 5 · 饮水 4 · …」（12px 次级色）。N = 本周各记录（专注段/饮水达标日/准时入睡/习惯完成/训练/起身）事件总数。
2. **连续推进条**：「连续 N 天至少推进 1 件」（进度条样式，成功色填充）。
3. **关联洞察区**：保留现有 lag-1 卡片，新增一张「睡眠关联」卡，文案：「少睡日的专注平均少 X 分钟」——用观察性关联口吻，标注「观察性关联」。
4. **维度点阵 + 模块折叠卡组**：整体收进折叠区，标题「查看各维度详情」，展开后才显示对比数据。
5. **移除**：score 完成率大环（它是隐性「未达标」呈现）；全页禁「只/仅/还差/未完成/落后」字样。
6. 页面入口处加一行小字「适合白天精力充足时回看」（12px 次级色）。

验收：首屏 = 小胜计数 + 连续推进（无 score 环、无维度点阵）；全页零「未完成」红字。

## 【批次 7 · 形态层改造】（2026-08-22 追加：让 5 个主页面「看起来就是」能量经营系统）

> 背景：机制已全部落地，但主页面第一视觉仍是旧「量化引擎」形态（完成率/功能列表），六句话与播客内容「看不见」。本批次给 5 个主页面注入能量经营的第一视觉。

### 7.1 今天页（schedule.html 首屏 Hero 区）——最重要
- **退役「今日推进 XX%」完成率环**（完成率=隐性未达标呈现）
- Hero 区改为「**今日盘面**」：四账户横向能量条，每行 = 账户名（体能/情感/思维/意志）+ 能量条 + 三态标签 + 一句话
  - 三态标签用中性词与中性色：**充实**（成功绿）/ **平稳**（品牌蓝）/ **待充电**（暖橙 #E8833A）——禁止「低/赤字/差/弱」等评价词
  - 能量条填充：充实 100% / 平稳 60% / 待充电 25%
  - 每账户一句话示例（零回顾陈述，只说现在）：
    - 体能：「昨夜睡眠达标，底座稳」/「今晚 23 点前睡，先守底线」
    - 情感：「情绪平稳，正是好状态」/「可以看看昨天的小胜，或做件小事」
    - 思维：「昨天产出扎实，今天可以攻坚」/「今天少切换，一次只做一件」
    - 意志：「目标在推进，方向感在线」/「回到目标，做最小的一步」
- 今日安排（进行中事件）保留在盘面右侧或下方

### 7.2 目标页（goals.html）
- 页头加一行「**意志账户**」语义：「方向 · 今天这一步：〔TodayStep 标题〕」+「连续推进 N 天」
- 目标列表副标题统一为「已推进 X 天」（正向计数）

### 7.3 今日安排页（schedule.html）
- 攻坚窗口（9:00-11:30）从 border 小条升级为**区块化主视觉**：该时段区域用浅金底色块（rgba(232,131,58,.12)）+ 左缘 3px #E8833A + 标签「攻坚窗口」
- 页头一行：「思维账户 · 高价值时段 9:00-11:30」

### 7.4 推进回顾页（review.html）
